Por que usamos o PISTA?

Ele evita que a classificação do produto seja feita apenas pelo nome. As perguntas identificam o que é, do que é feito, como foi produzido, como é apresentado e sua origem e uso.

Escolha uma das integrações. Os dados ficam salvos somente neste navegador.

Recomendação: use uma Firebase Cloud Function quando publicar o portal. Assim as chaves privadas não ficam expostas no navegador. Para testes sem servidor, o EmailJS pode ser utilizado.
O template pode usar: to_email, protocol, company_name, requester_name, requester_email, document_type, recipient_name, total, urgency, requested_at e summary.
O portal enviará um POST JSON com o pedido. A função deverá validar, salvar no Firebase e disparar o e-mail.
